# ケモスラ（仮）

小太りなハイエナ獣人の盗賊「コタロー」を操作する、2Dアクション×ハクスラRPGの操作プロトタイプです。

## 遊ぶ

公開版: https://imomoti666-s.github.io/-/

## 現在できること

- コタローの移動、ジャンプ、回避
- MAIN 1／MAIN 2の二枠装備
- 戦闘中の武器切り替え
- 短剣の高速連撃
- 斧の大振り攻撃
- 弓のチャージ射撃
- 装備画面から二枠を自由に変更
- キーボードとスマートフォンのタッチ操作
- 図形で表現した三種類の訓練用敵

プレイヤー本体と武器は生成画像を用いた多関節リグで描画し、敵・地形・攻撃エフェクトは開発用の図形で構成しています。

## 操作

| 動作 | キーボード |
|---|---|
| 移動 | `A` / `D` または左右キー |
| ジャンプ | `Space` / `W` / 上キー |
| 攻撃 | `J` / `Z` / `Enter` |
| 回避 | `Shift` |
| 武器切り替え | `Q` / `X` |
| MAIN 1 / 2を直接選択 | `1` / `2` |
| 位置とHPのリセット | `R` |

弓は攻撃ボタンを押し続けてチャージし、離すと発射します。

## ローカル起動

静的ファイルのみで動作します。リポジトリのルートでHTTPサーバーを起動してください。

```sh
python -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

## 素材方針

- コタローと三武器: ChatGPTで生成
- 敵、地形、背景、VFX: Canvasによる図形描画
- 効果音: Web Audio APIによるリアルタイム合成

このリポジトリの画像素材を別用途で再配布・再利用する場合は、作者へ確認してください。
