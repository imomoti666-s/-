# ケモスラ（仮）

小太りなハイエナ獣人の盗賊「コタロー」を操作する、2Dアクション×ハクスラRPGの操作プロトタイプです。

## 遊ぶ

公開版: https://imomoti666-s.github.io/-/

## 現在できること

- コタローの移動、ジャンプ、回避
- 腕・脚・胴体を一枚に統合した全身スプライトアニメーション
- MAIN 1／MAIN 2の二枠装備
- 戦闘中の武器切り替え
- 短剣・斧・弓それぞれの弱攻撃と武器固有の強攻撃
- 停止／移動／回避／空中で分岐する、3武器×弱強×4状態＝24系統の攻撃
- 各攻撃を20段階で補間する全身アニメーション
- 弱攻撃では入力にない自動跳躍・自動突進を行わない状態固定型の挙動
- 装備画面から二枠を自由に変更
- キーボードとスマートフォンのタッチ操作
- 図形で表現した三種類の訓練用敵

プレイヤー本体と攻撃中の武器は、ChatGPTで生成した全身アニメーションシートで描画しています。敵・地形・攻撃エフェクトは開発用の図形で構成しています。

## 操作

| 動作 | キーボード |
|---|---|
| 移動 | `A` / `D` または左右キー |
| ジャンプ | `Space` / `W` / 上キー |
| 弱攻撃 | `J` / `Z` / `Enter` |
| 強攻撃 | `K` / `C` |
| 回避 | `Shift` |
| 武器切り替え | `Q` / `X` |
| MAIN 1 / 2を直接選択 | `1` / `2` |
| 位置とHPのリセット | `R` |

弓は弱／強攻撃ボタンを押し続けてチャージし、離すと発射します。攻撃開始時の停止／移動／回避／空中状態によってモーションと性能が変わります。

## ローカル起動

静的ファイルのみで動作します。リポジトリのルートでHTTPサーバーを起動してください。

```sh
python -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

## 素材方針

- コタローと三武器: ChatGPTで生成
- 通常動作10コマ、空中系8コマ、六つの攻撃シートに各20キー姿勢を全身単位で収録
- 攻撃中は5つの主要キー姿勢を20段階へ補間し、体格・四肢・尻尾の一貫性を維持
- 敵、地形、背景、VFX: Canvasによる図形描画
- 効果音: Web Audio APIによるリアルタイム合成

このリポジトリの画像素材を別用途で再配布・再利用する場合は、作者へ確認してください。
